Область определения и область значений

Область определения D(f)

Множество всех значений аргумента x, для которых функция имеет смысл.

🟢 Область значений E(f)

Множество всех значений функции y, которые она может принимать.

📝 Пример 1: y = x²

D(f) = (-∞; +∞) — x может быть любым числом

E(f) = [0; +∞) — квадрат всегда неотрицателен

📝 Пример 2: y = 1/x

D(f) = (-∞; 0) ∪ (0; +∞) — x ≠ 0

E(f) = (-∞; 0) ∪ (0; +∞) — y ≠ 0

💡 Запомни: Область определения — это «иксы», область значений — это «игреки»!

📈📉 Возрастание и убывание функции

🔺 Возрастание

Функция возрастает на промежутке, если большему значению аргумента соответствует большее значение функции.

Если x₂ > x₁, то f(x₂) > f(x₁)

🔻 Убывание

Функция убывает на промежутке, если большему значению аргумента соответствует меньшее значение функции.

Если x₂ > x₁, то f(x₂) < f(x₁)

📊 y = x²

Убывает: на (-∞; 0]

Возрастает: на [0; +∞)

🎯 Нули функции и промежутки знакопостоянства

⚫ Нули функции

Значения аргумента x, при которых y = 0.

На графике — это точки пересечения с осью Ox.

➕➖ Промежутки знакопостоянства

Промежутки, на которых функция сохраняет знак (положительна или отрицательна).

📝 Пример: y = x² - 4

Нули функции: x² - 4 = 0 → x = -2 и x = 2

y > 0 (положительна): на (-∞; -2) ∪ (2; +∞)

y < 0 (отрицательна): на (-2; 2)

📏 Ограниченность функции

🔽 Ограничена снизу

Существует число m, такое что f(x) ≥ m для всех x из области определения.

🔼 Ограничена сверху

Существует число M, такое что f(x) ≤ M для всех x из области определения.

📊 y = x²

Ограничена снизу: y ≥ 0

Не ограничена сверху

Наименьшее значение: yнаим = 0 (при x = 0)

📊 y = -x²

Ограничена сверху: y ≤ 0

Не ограничена снизу

Наибольшее значение: yнаиб = 0 (при x = 0)

💡 Совет: Если функция ограничена и снизу, и сверху — она просто ограничена!

📐 Свойства линейной функции y = kx + m

Основные свойства:

  1. D(f) = (-∞; +∞) — определена для всех x
  2. E(f) = (-∞; +∞) — принимает все значения
  3. Возрастает при k > 0
  4. Убывает при k < 0
  5. Не ограничена ни снизу, ни сверху
  6. Непрерывная на всей числовой прямой

Свойства квадратичной функции y = ax² + bx + c

Случай a > 0 (ветви вверх)

  1. D(f) = (-∞; +∞)
  2. Убывает на (-∞; -b/(2a)], возрастает на [-b/(2a); +∞)
  3. Ограничена снизу, не ограничена сверху
  4. yнаим в вершине параболы
  5. E(f) = [yнаим; +∞)
  6. Выпукла вниз

Случай a < 0 (ветви вниз)

  1. D(f) = (-∞; +∞)
  2. Возрастает на (-∞; -b/(2a)], убывает на [-b/(2a); +∞)
  3. Ограничена сверху, не ограничена снизу
  4. yнаиб в вершине параболы
  5. E(f) = (-∞; yнаиб]
  6. Выпукла вверх

🎮 Практика: Найди свойства функции

1 Задача: Дана функция y = x² - 6x + 5. Найдите:
а) Область определения
б) Нули функции
в) Промежутки возрастания и убывания
г) Наименьшее значение функции
Решение:
а) D(f) = (-∞; +∞)
б) x² - 6x + 5 = 0 → x₁ = 1, x₂ = 5 (нули функции)
в) Вершина: x₀ = -(-6)/(2·1) = 3
   Убывает на (-∞; 3], возрастает на [3; +∞)
г) yнаим = y(3) = 9 - 18 + 5 = -4
2 Задача: По графику функции y = f(x) определите промежутки, на которых функция положительна.
Решение:
Функция положительна там, где график лежит выше оси Ox.
Нужно найти промежутки, где y > 0.

Ещё задачи для практики

3 Задача: Функция задана формулой y = -2x + 8. Найдите:
а) Область определения и область значений
б) Нуль функции
в) Промежутки знакопостоянства
г) Возрастает или убывает?
Решение:
а) D(f) = (-∞; +∞), E(f) = (-∞; +∞)
б) -2x + 8 = 0 → x = 4 (нуль функции)
в) y > 0 при x < 4; y < 0 при x > 4
г) k = -2 < 0, значит функция убывает
4 Задача: y = x. Найдите область определения, область значений и промежутки монотонности.
Решение:
D(f) = [0; +) — корень определён только для x ≥ 0
E(f) = [0; +∞) — корень всегда неотрицателен
Функция возрастает на [0; +∞)
5 Задача: y = 1/x. Найдите область определения, область значений и промежутки монотонности.
Решение:
D(f) = (-∞; 0) ∪ (0; +∞) — x ≠ 0
E(f) = (-∞; 0) ∪ (0; +∞) — y ≠ 0
Функция убывает на (-∞; 0) и на (0; +∞)
