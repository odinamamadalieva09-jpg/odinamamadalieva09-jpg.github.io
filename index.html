Действительные числа

Определение:
ℝ — множество всех действительных чисел (вещественных чисел) — это объединение множества рациональных чисел ℚ и множества иррациональных чисел 𝕀.
ℝ = ∪ 𝕀
Важно помнить:

Каждое действительное число можно изобразить точкой на координатной прямой, и каждой точке координатной прямой соответствует единственное действительное число.

Рациональные числа (ℚ)

Определение:
ℚ — множество чисел, которые можно представить в виде дроби m/n, где m — целое число, n — натуральное число.
= { m/n | m ∈ ℤ, n ∈ ℕ }
Примеры рациональных чисел:
  • Целые числа: -3, 0, 5, 100
  • Обыкновенные дроби: 1/2, -3/4, 7/8
  • Десятичные конечные: 0,5; 2,75; -0,125
  • Десятичные периодические: 0,(3) = 1/3
Свойства:
  • Сумма рациональных чисел — рациональное число
  • Разность рациональных чисел — рациональное число
  • Произведение рациональных чисел — рациональное число
  • Частное рациональных чисел (кроме деления на 0) — рациональное число

Иррациональные числа (𝕀)

Определение:
𝕀 — множество действительных чисел, которые нельзя представить в виде дроби m/n, где m — целое число, n — натуральное число.
Примеры иррациональных чисел:
  • √2 ≈ 1,41421356... (непериодическая десятичная дробь)
  • √3, √5, √7 (корни из простых чисел)
  • π ≈ 3,14159265... (число Пи)
  • e ≈ 2,71828182... (число Эйлера)
  • 0,101001000100001... (непериодическая дробь)
Характеристики:
  • Представляются бесконечными непериодическими десятичными дробями
  • Не могут быть точно выражены обыкновенной дробью
  • На координатной прямой занимают «промежутки» между рациональными числами

Взаимосвязь множеств:
ℕ ⊂ ℤ ⊂ ⊂ ℝ и 𝕀 ℝ, причём ℚ ∩ 𝕀 = ∅ (пересечение пустое)

Свойства действий над действительными числами

1. Переместительный закон

a + b = b + a
a · b = b · a

2. Сочетательный закон

(a + b) + c = a + (b + c)
(a · b) · c = a · (b · c)

3. Распределительный закон

a · (b + c) = a·b + a·c

4. Существование нуля и единицы

a + 0 = a
a · 1 = a
Важно:

Эти свойства выполняются для любых действительных чисел (как рациональных, так и иррациональных).

Примеры действий над действительными числами

Сложение и вычитание:

Пример 1:

√2 + 3√2 = 4√2

(складываем как подобные слагаемые)

Пример 2:

π + 2 ≈ 3,14 + 2 = 5,14

(приближённое значение)

Умножение и деление:

Пример 3:

√3 · √5 = √15

Пример 4:

2√6 : √2 = 2√3

(так как √6/√2 = 3)

Важное свойство:
Сумма (разность) рационального и иррационального числа — всегда иррациональное число.
Произведение (частное) ненулевого рационального и иррационального числа — всегда иррациональное число.

Основные выводы:

  • Свойства арифметических действий выполняются для всех ℝ
  • Иррациональные числа — бесконечные непериодические десятичные дроби
